# i3 configuration

Custom i3 window manager configuration with enhanced keybindings for productivity.

## Configuration

The i3 configuration files are located in the `~/.config/i3/` directory. The main configuration file is `config`.

## Keybindings

### 🚀 Launchers

| Shortcut     | Action                |
| ------------ | --------------------- |
| Mod + Return | Open terminal         |
| Mod + R      | Rofi main menu        |
| Mod + E      | Applications launcher |
| Mod + T      | Tmux session switcher |
| Mod + Tab    | Window switcher       |

### 🧠 Navigation

| Shortcut | Action                    |
| -------- | ------------------------- |
| Mod + H  | Focus window to the left  |
| Mod + J  | Focus window below        |
| Mod + K  | Focus window above        |
| Mod + L  | Focus window to the right |

### 🧱 Window Movement

| Shortcut        | Action            |
| --------------- | ----------------- |
| Mod + Shift + H | Move window left  |
| Mod + Shift + J | Move window down  |
| Mod + Shift + K | Move window up    |
| Mod + Shift + L | Move window right |

### 📐 Layout Control

| Shortcut           | Action                   |
| ------------------ | ------------------------ |
| Mod + Ctrl + H     | Horizontal split         |
| Mod + Ctrl + V     | Vertical split           |
| Mod + Ctrl + S     | Stacking layout          |
| Mod + Ctrl + T     | Tabbed layout            |
| Mod + Ctrl + Space | Toggle split orientation |

### 🪟 Window States

| Shortcut        | Action                       |
| --------------- | ---------------------------- |
| Mod + F         | Toggle fullscreen            |
| Mod + S         | Toggle sticky mode           |
| Mod + Shift + F | Toggle floating mode         |
| Mod + Space     | Switch focus tiling/floating |
| Mod + Q         | Focus parent container       |

### 📦 Scratchpad

| Shortcut | Action                    |
| -------- | ------------------------- |
| Mod + U  | Send window to scratchpad |
| Mod + I  | Show scratchpad selector  |

### 💀 Destructive

| Shortcut        | Action              |
| --------------- | ------------------- |
| Mod + Shift + X | Kill focused window |

### ⚙️ System

| Shortcut      | Action           |
| ------------- | ---------------- |
| Mod + Alt + R | Restart i3       |
| Mod + Alt + C | Reload i3 config |

### 🧘 Zen Mode

| Shortcut | Action                |
| -------- | --------------------- |
| Mod + Z  | Center / focus window |
